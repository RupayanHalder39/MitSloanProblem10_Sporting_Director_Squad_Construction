# Data and redistribution note

This public repository does **not** contain raw data, player-level records, canonical
director-club-season rows, archived webpages, SQL dumps, parquet files, or database files.

## Included

Only aggregate scientific evidence classified as safe for public release:

- summary distributions for the four locked behavioural measures;
- the complete aggregate behaviour-by-context association table;
- quality and season sensitivity summaries;
- sample-composition and profile-survival summaries;
- claim, limitation, and reproducibility audit tables.

## Excluded

The canonical context and behavioural panels inherit unresolved redistribution questions from their
upstream sources. They are excluded even though they contain derived club-season aggregates rather
than player-level rows. The smaller public package is intentional.

Market value is a proxy, not a transfer fee, budget, spending figure, profit, or accounting value.
Inferred player movement is not an observed transaction.
